# Утилита для пакетного переименования файлов

Утилита командной строки для массового переименовывания файлов в
указанной директрории по определенному пользователем шаблону.
Передача параметров для переименовывания файлов осуществляется
через аргументы командной строки.

Проект находится в разработке.
