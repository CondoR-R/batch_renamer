# 📁 Batch Renamer (Утилита пакетного переименовывания файлов)

Утилита командной строки для пакетного переименования файлов с гибкими шаблонами. Поддерживает режим «сухого» прогона (dry‑run), подстановку счётчика. Написана на Python с использованием **только стандартной библиотеки**, кроме тестов, для них используется фреймворк `pytest`.

## ✨ Возможности

- Переименование всех файлов в указанной папке по шаблону
- Указание целевой папки через `--path` (относительный или абсолютный путь)
- Поддержка подстановки:
  - `{counter}` – порядковый номер (с форматированием, например `{counter:03d}`)
- Режим `--dry-run` – предварительный просмотр без фактического переименования
- Защита от конфликтов имён (пропуск файла с конфликтным новым именем и вывод предупреждения на экран)
- Кроссплатформенность (Linux, macOS, Windows)

## 🚧 В планах

- Подстановка расширения файла (`{ext}`)

- Рекурсивная обработка подпапок (`--recursive`)

- Подстановка даты изменения файла (`{date}`)

- Замена подстрок (`--replace`)

- Поддержка фильтров по расширениям

## ⚙️ Установка и запуск

### Требования

- Python 3.10 или выше (стандартная библиотека)

### 1. Клонирование репозитория

```bash
git clone https://github.com/CondoR-R/batch_renamer.git
cd batch_renamer
```

### 2. Создание виртуального окружения (рекомендуется)

Установка позволяет запускать утилиту командой batch-renamer из любого места.

```bash
# Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate

# Установите пакет в режиме разработки (editable)
pip install -e .
```

После установки утилита доступна как `batch-renamer`:

```bash
batch-renamer --pattern "photo_{counter:03d}{ext}" --dry-run
```

### 3. Запуск без установки (из исходников)

Если вы не хотите устанавливать пакет, можно запустить скрипт напрямую:

```bash
python -m batch_renamer [опции]
```

Пример:

```bash
python -m batch_renamer --pattern "photo_{counter:03d}.png" --dry-run
```

## 🚀 Использование

### Аргументы командной строки

| Аргумент | Описание |
|----------|----------|
| `--path` | Папка с файлами (по умолчанию текущая) |
| `--pattern` | Шаблон имени (обязательный) |
| `--dry-run` | Только показать, что будет переименовано, без изменений |
| `--help` | Показать справку |

### Примеры

#### Простой шаблон со счётчиком

```bash
batch-renamer --pattern "photo_{counter:03d}.png"
```

Результат: `photo_001.png`, `photo_002.png`, … (сортировка по имени файла).

#### Режим сухого прогона

```bash
batch-renamer --pattern "new_{counter:03d}.png" --dry-run
```

Выведет таблицу старых и новых имён, ничего не меняя.

## 🧪 Тестирование

Для тестирования используется фреймворк **pytest** (не входит в стандартную библиотеку, поэтому его нужно установить отдельно).

### Установка зависимостей для разработки

```bash
pip install pytest
```

#### Запуск тестов

```bash
pytest
```

Или с подробным выводом:

```bash
pytest -v
```

Тесты находятся в директории `tests/`.
